Scripts, data, and figures from "The monophyly of Asteraceae: Unravelling conflicting phylogenomic signals surrounding the origin of the family".

## File structure:

### Alignments
Contains a compressed file with all gene alignments, plus a txt file with the alignment statistics from each alignment obtained with AMAS. 

### ASTRALtrees
Contains inputs, outputs, and logs from the ASTRAL analysis.

### GeneTrees
Contains all gene trees produced with IQ-TREE.

### LikelihoodMapping
Contains the simulated topologies used for likelihood mapping (test_topoX.tre), files used for producing figures (triplets.tsv, alignment_info_with_triplets.csv), files with the original likelihood calculated by IQ-TREE before normalization (topoX.txt), plus multiple plots produced with these input files.

### QuartetSampling
Contains all files used in the QuartetSampling analysis, all output files, and plots produced with the script from https://github.com/ShuiyinLIU/QS_visualization.

### scripts
Contains R scripts used to produce figures and tables. 

### SupplementalMaterial
Contains the Supplemental Files submitted with the article.
